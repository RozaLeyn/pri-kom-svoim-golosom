# «При ком?»

Локальная мобильная игра кампании «Своим голосом»: 8 утверждённых историй об Израиле, 4 имени на выбор и переворот карточки после ответа.

## Запуск

Node.js 22 или новее. Единственная зависимость — `@fontsource/geologica@5.3.0`, версия зафиксирована в package-lock.json. Сборка берёт только четыре нужных WOFF2 из установленного npm-пакета; никаких сетевых загрузок в build или во время игры.

```sh
npm ci
npm run verify
npm run dev
```

Открыть http://127.0.0.1:4178/games/pri-kom/. `npm run build` создаёт `dist/`; `npm run preview` обслуживает собранную версию. Все пути к ресурсам относительные, игра может жить в `/games/pri-kom/`. Сервер нужен только для локального просмотра, публичная версия — обычная статика.

## Правила

- Восемь событий без повторов: Эйнштейн, снег в Тель-Авиве, ICQ, Beatles, бойкот коттеджа, McDonald’s, Евровидение, птитим.
- Порядок вопросов и четырёх имён перемешивается. Правильный премьер может повторяться.
- Один тап фиксирует ответ; его нельзя изменить. После ответа карточка переворачивается, показывая имя, год, начало истории. Полный текст и источники раскрываются на месте.
- Один раз за игру можно убрать два неверных варианта. Ответ засчитывается обычным образом, использование подсказки отмечается.
- Итог — число верных ответов и хронология всех событий с раскрываемыми историями.
- Повторное прохождение использует те же восемь утверждённых историй в новом порядке. Банк из 32 событий пока не подготовлен.
- Движение отключается по системной настройке reduced motion; доступны клавиатура, фокус и текстовые обозначения результатов.

Адрес анкеты взят из актуального бренд-стандарта. Обе ссылки открываются в новой вкладке; ответы и баллы в URL не добавляются.

TT Travels Next Black подключён только лицензированным WOFF2. Geologica подключается из npm-пакета и копируется в сборку локально, лицензия OFL прилагается. Исходники коммерческого шрифта и документы покупки не включены. Публикацию на новом домене согласовывать с владельцем лицензии.

## Приватность

Нет аккаунтов, cookies, localStorage, аналитики, API, ключей или токенов. Ответы находятся только в оперативной памяти вкладки; обновление страницы сбрасывает игру. Источники и регистрация — внешние сайты. Их собственные правила обработки данных не контролируются игрой. `.env*` исключены из Git.

## Данные и проверка

Все восемь текстов и источники — `src/data.js`. Для Beatles 1966 — год обсуждения в Кнессете, не дата первоначального отказа в гастролях. Вопрос не приписывает премьеру единоличное авторство решения. События не оценивают заслуги премьеров или политические взгляды игрока.

Проверки ядра: структура вопросов, защита от повторного ответа, неправильные ответы, подсказка и завершение после восьмого. Проверено 10 сентября 2026: 7 автоматических тестов и статическая сборка прошли. Playwright прошёл полный цикл на ширинах 320, 390 и 1280 px: смешанные и верные ответы, подсказка, все 8 историй, финальная хронология, повтор, сброс при обновлении, клавиатура и reduced motion. Нет горизонтального переполнения, ошибок консоли, нарушений CSP, внешних запросов и записи в хранилища браузера. Скриншоты проверки — `output/` (не входят в сборку). Браузерная проверка: `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/browser-check.mjs` при работающем `npm run preview`.

Регистрационная ссылка дополнительно открыта в браузере: найдена форма с якорем `join`, полями имени, города, email и телефона. Данные не вводились и форма не отправлялась.

Статус: реализация локальная; публичная публикация не выполнялась. Превью `public/preview.png` (1200×630) и `public/favicon.png` включены в сборку; `og:image` указывает на будущий адрес https://info.svoimgolosom.co.il/games/pri-kom/preview.png. Это адрес размещения, не подтверждение публикации. В превью использован Geologica Bold и готовые брендовые PNG/JPEG; коммерческий веб-шрифт не применялся для создания статичной картинки.
