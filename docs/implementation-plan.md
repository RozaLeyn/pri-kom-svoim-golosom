# «При ком?» Implementation Plan

**Goal:** Реализовать утверждённую игру: 8 событий, 4 имени, переворот с историей, итоговая хронология.
**Architecture:** Статическое приложение с отдельными модулями данных, чистой логики и интерфейса. Все ресурсы локальные, относительные пути совместимы с /games/pri-kom/.
**Tech Stack:** HTML, CSS, JavaScript modules, Node test runner, Playwright.

- [x] Написать и запустить тесты: восемь уникальных карточек, однозначные ответы, подсказка один раз, защита от повторного ответа, финал после восьмого.
- [x] Реализовать данные утверждённых карточек (Эйнштейн, снег, ICQ, Beatles, коттедж, McDonald’s, Евровидение, птитим), модуль логики и интерфейс.
- [x] Добавить готовый логотип, CTA «Идёшь голосовать? Регистрируйся!» с https://svoimgolosom.co.il/qmYm#join, фирменные шрифты и персонажа.
- [x] Проверить мобильное прохождение, клавиатуру, reduced motion, сборку под подпутём, отсутствие внешних запросов и хранения ответов.
- [x] Обновить README и открыть локальный результат. Публикация не входит в текущий этап.
